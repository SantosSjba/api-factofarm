# Términos de uso — FactoFarm

Al usar FactoFarm usted acepta estos términos.

## 1. Servicio

FactoFarm es un software en la nube para gestión de boticas y farmacias (POS, inventario, compras, usuarios y módulos contratados). El acceso es por invitación / contrato.

## 2. Cuentas y seguridad

El cliente es responsable de las credenciales de sus usuarios, de asignar roles adecuados y de las operaciones realizadas con sus cuentas.

## 3. Datos

El cliente garantiza contar con base legal para registrar datos de sus clientes/pacientes. FactoFarm actúa como encargado tecnológico según el contrato y la política de privacidad.

## 4. Facturación electrónica

La emisión de comprobantes electrónicos SUNAT depende de la configuración del cliente con un proveedor OSE/PSE y del cumplimiento tributario del establecimiento. En entornos de prueba o sin OSE, el sistema puede operar con nota de venta / modo simulado.
